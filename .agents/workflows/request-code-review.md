# Requesting Code Review

## When to Use

Use after completing a major feature, before merging a branch, or when you want verification that work meets requirements.

## Process

1. **Load the FULL request-code-review skill folder** (Skill Loading Protocol):
   - `list_dir` on `.agents/skills/request-code-review/`
   - `view_file` on `SKILL.md` AND every file in `references/`, `agents/`, `scripts/`
2. Complete the pre-review checklist before requesting review
3. Address all findings before claiming completion
